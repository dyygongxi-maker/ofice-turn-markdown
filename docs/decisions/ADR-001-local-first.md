# ADR-001：采用本地优先处理

## Status

Accepted

## Date

2026-09-01

## Context

目标用户要处理个人办公文件，首要用途是知识归档和 AI 阅读。云端上传会增加隐私顾虑、网络依赖和账户系统成本。

## Decision

MVP 在 Windows 本机运行，界面仅服务于本机回环地址。运行时不上传文档、不收集正文，也不保存云端副本。

## Alternatives Considered

### 在线转换服务

- 优点：无需本地安装，未来公开服务部署方便。
- 缺点：文件外流风险、账户和成本问题、不能满足纯本地要求。
- 结论：当前拒绝。

### 原生桌面应用

- 优点：更自然的文件系统集成。
- 缺点：首版需要处理打包、签名和桌面框架选择。
- 结论：保留为后续分发方式；不阻塞本地核心验证。

## Consequences

- 所有路径、临时文件和日志需遵循本地数据边界。
- 未来引入网络能力必须新建 ADR，并经过明确确认。
